# 評価

## vite, importmap

viteが使える状況では、viteが無難。

importmapは、バニラJSで、JSモジュールを使いたいときにあったほうがいい機能だけど、viteに比べると、管理はかなり厄介になる。

Firefoxのimportmapは厳格で、importmapを複数定義できなかったり、モジュール実行する前に定義が必要だったりする。

importmapを使いたい場合は、注意が必要。

## javascript, typescript

javascriptは、IDEで無理が出やすい。

特殊な状況以外では、typescriptが無難。

## vue, react

reactはメンテナンスコストが高くなりがちなので非推奨。

このレポジトリ内にあるコードは、あくまで、実装例です。

なぜ、非推奨なのかは、実装例でVueと比較してあるので、見ればわかると思う。

reactは、革新的なアイデアだったけど、テンプレートエンジンではないため、しんどくなる部分がある。

vueは、reactからしんどい部分を除去してあるので、比較的、実用的。

全体を比較すると、よくわかると思うけど、そこまで全体を見ることは、一般的には難しいと思う。

よくわからない人は、vue、composition API、defineModelでいいと思う。

reactは、構造上、実装のための実装がかさんでいくようにできている。

コボルのような達成感は得られるだろうけど、メンテナンスが大変になっていく。

## アトミックデザイン

アトミックデザインはあくまで実装例で非推奨。

理由は、依存が複雑になって変更が危険になるためです。

個人的な趣味の範囲で実装すること自体は楽しいと思います。

ただし、個人的な趣味の範囲にとどめて、実務では利用しないほうが無難。

## Turbo Drive

Turbo Driveの実装例もありますが、全ページ常時WebSocket接続が必要な状況で、MPAにしたいとき以外は非推奨。

なぜ非推奨かは、実装例を見ればわかると思う。

これを使うとMPAとSPAの要素がまざった実装になり複雑化する。

予期せぬ副作用が起きやすい。

さらに、今の技術だと、使っても使わなくても、UXにほとんど違いがない。

逆に、ページ遷移の挙動がわかりにくくなるため、UXが悪化することもある。

## 部品として、laravelのコンポーネントを利用

PHPを、このプロジェクトのように利用するのは、お勧めしません。

Laravelを使ったほうが無難。

なぜなら、プロジェクトの新規参加者が慣れるのに、余計な時間がかかるから。

Laravelはある程度融通が利くフレームワークだけど、だからと言って、特殊な実装をするのも、同じ理由で非推奨。

## PHPのORM

PHPのORMは、Eloquentが無難だと思う。

ほかのORMでは、複雑すぎたり、潰しがきかない設計だったり、使える人が少なかったりする。

Eloquentは、オーソドックスなアクティブレコードモデルで、ある程度キレイにまとまっていて、直感的に利用しやすい。

## お手軽SPA風ツール

htmxで、ある程度まではできるけど、複雑なものや、詳細までカスタマイズが必須の場合はvueにするしかない。

だから、基本的には、アイランドアーキテクチャでvueを使うほうが無難だと思う。

これは、livewire、turbo frames, turbo streamsも同様。

ただ、livewireは、レイヤーが複雑に混ざるため、認知負荷が高い。

turboは、副作用が多い。

そのため、お手軽SPA風ツールのなかでは、htmxが比較的無難かも。

## tailwind

CSS管理の最後の手段だと思う。

@applyの存在を知っているかいないかで、評価が大きく変わると思う。

@applyは、ボタンなど共通部品だけにしないと、これを使う意味がなくなる。

@applyで作るクラスには、共通のプレフィックスをつけるほうが無難。

@applyを全く使わない運用は非推奨。

tailwind4は、@applyでクラスの継承ができないので、tailwind3のほうが管理が楽だと思う。

## docker

dockerは、実務だと、環境の共有ができて便利だけど、学習用途では使わないほうがいい。

学習用途だったら、wsl+ubuntuが、本番環境に近く、いろいろ試しやすいので、一番都合がいいと思う。

その次が、macのネイティブ環境。

windowsネイティブからdockerを動かすと、ファイルシステムの影響で遅くなるため、node_modulesをボリュームにするなどの工夫が必要になるので、wslから利用したほうがいい。
